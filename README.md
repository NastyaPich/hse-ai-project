## 📌 Тема

Проект: **Прогнозирование цен на недвижимость Лондона и оценка влияния факторов**.

Цена на недвижимость — один из ключевых индикаторов состояния рынка и спроса на жильё. Мы строим модели, которые по характеристикам объекта (площадь, тип жилья, форма собственности, энергокласс), его положению (координаты, расстояние до центров, район), и истории продаж прогнозируют цену продажи (макрофакторы, например ставку Банка Англии, тоже проверяли, но она не улучшила прогноз), и измеряем, какие группы факторов улучшают прогноз сильнее всего. Итоговый результат — сервис оценки стоимости жилья в Лондоне. По адресу и параметрам объекта он:
- оценивает цену и показывает **диапазон**, в котором она скорее всего лежит;
- **объясняет оценку**: какие факторы (площадь, район, транспорт, история продаж) подняли или снизили цену;
- показывает **похожие продажи рядом**;
- подставляет параметры жилья **по адресу** из данных, чтобы не вводить всё вручную;
- **проверяет цену объявления**: насколько она выше или ниже рыночной оценки;
- работает через API и простой **веб-интерфейс с картой цен**.

**Границы применимости:** модель обучается только на сделках в Лондоне, поэтому её результаты применимы только к лондонскому рынку жилья. Для других рынков — других городов Англии и тем более других стран, например Москвы, — нужны свои данные и отдельная проверка: цены, законы, формы собственности и важные факторы там устроены иначе.

**Данные:** [London House Price Prediction: Advanced Techniques (Kaggle)](https://www.kaggle.com/competitions/london-house-price-prediction-advanced-techniques). Около 266 тысяч продаж 1995–2023 годов (train) и 16,5 тысячи продаж 2024 года (test). Все объекты лежат в почтовых районах Лондона. В таблицах есть координаты, площадь, число комнат, тип жилья, форма собственности, энергокласс, дата продажи и цена. Валидация идёт по времени: обучаемся на прошлом, проверяем на будущем.

**Ключевые вызовы:** сдвиг цен со временем (рост рынка, смена ставки), выбросы и ошибки в ценах, пропуски в площади (около 5% строк), разная история адресов у train и test.

**Подход:**
1. Разведочный анализ (EDA) лондонских данных.
2. Обогащение таблиц признаками по одной группе за раз; вклад каждой группы измеряется абляцией на проверке по времени.
3. Классический ML (бейзлайны, градиентный бустинг), выбор цели (цена или цена за м², решается отдельно), затем нейронные сети и сравнение.
4. Сервис: API на FastAPI (цена, диапазон, объяснение, похожие продажи), затем ввод по адресу, проверка цены объявления и веб-интерфейс с картой.

**Гипотезы для проверки:**
- чем больше площадь, тем ниже цена за м²;
- ближе к центру и транспорту выше цена за м²;
- какие группы факторов (центры, район, ставка, прошлые продажи) сильнее всего улучшают прогноз.

```

│   └── london/            # распакованные train.csv, test.csv
```

Подробно о признаках, источниках и защите от утечек: [`FEATURES.md`](FEATURES.md).

## 🚀 Как запустить

Все команды выполняются из корня репозитория.

**1. Окружение**

```bash
pip install -r requirements.txt
```

**2. Данные**

```bash
unzip data/raw/london-house-price-prediction-advanced-techniques.zip -d data/raw/london
```

**3. EDA.** Откройте `notebooks/EDA.ipynb`. Ноутбук сам найдёт данные: распакованные CSV, архив или (если ничего нет) скачает архив с GitHub.

**4. Внешние данные** (нужен интернет, подробности в разделе «Данные» выше):

```bash
python src/fetch_external.py stations
python src/fetch_external.py postcodes
```

Файл IMD 2019 (`ID 2019 for London.xlsx`) скачиваем вручную с [London Datastore](https://data.london.gov.uk/dataset/indices-of-deprivation) в `data/external/`.

**5. Основная база** (очистка, признаки, итоговый набор):

```bash
python src/build_dataset.py
```

Результат в `data/processed/`: `train_enriched.csv` и `test_enriched.csv` (все признаки и флаги очистки), `train_final.csv` и `test_final.csv` (итоговые 15 признаков, флаги и заполненные пропуски). Почему выбраны именно эти признаки, описано в [`FEATURES.md`](FEATURES.md) и в разделе 7 `EDA.ipynb`.

**6. Проверка вклада групп признаков** (абляция на 2021–2023 годах, 10–30 минут в зависимости от компьютера):

```bash
python src/ablation.py --train data/processed/train_enriched.csv
```

Результат: `reports/ablation_multi_result.csv`. Для быстрой проверки можно взять один год: `--years 2023`.
