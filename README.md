## 📌 Тема

Проект: **Прогнозирование цен на недвижимость Лондона и оценка влияния факторов**.

Цена на недвижимость — один из ключевых индикаторов состояния рынка и спроса на жильё. Мы строим модели, которые по характеристикам объекта (площадь, тип жилья, форма собственности, энергокласс), его положению (координаты, расстояние до центров, район), истории продаж и макрофакторам (ставка Банка Англии) прогнозируют цену продажи, и измеряем, какие группы факторов улучшают прогноз сильнее всего. Итоговый результат — сервис, который по адресу и параметрам объекта оценивает цену.

**Данные:** [London House Price Prediction: Advanced Techniques (Kaggle)](https://www.kaggle.com/competitions/london-house-price-prediction-advanced-techniques). Около 266 тысяч продаж 1995–2023 годов (train) и 16,5 тысячи продаж 2024 года (test). Все объекты лежат в почтовых районах Лондона. В таблицах есть координаты, площадь, число комнат, тип жилья, форма собственности, энергокласс, дата продажи и цена. Валидация идёт по времени: обучаемся на прошлом, проверяем на будущем.

**Ключевые вызовы:** сдвиг цен со временем (рост рынка, смена ставки), выбросы и ошибки в ценах, пропуски в площади (около 5% строк), разная история адресов у train и test.

**Подход:**
1. Разведочный анализ (EDA) лондонских данных.
2. Обогащение таблиц признаками по одной группе за раз; вклад каждой группы измеряется абляцией на проверке по времени.
3. Классический ML (бейзлайны, градиентный бустинг), выбор цели (цена или цена за м², решается отдельно), затем нейронные сети и сравнение.
4. Сервис на FastAPI.

**Гипотезы для проверки:**
- чем больше площадь, тем ниже цена за м²;
- ближе к центру и транспорту выше цена за м²;
- какие группы факторов (центры, район, ставка, прошлые продажи) сильнее всего улучшают прогноз.

## 🚀 Как запустить

Все команды выполняются из корня репозитория.

**1. Окружение**

```bash
pip install -r requirements.txt
```

**2. Данные**

```bash
unzip data/raw/london-house-price-prediction-advanced-techniques.zip -d data/raw/london
```

**3. EDA.** Откройте `notebooks/EDA.ipynb`. Ноутбук сам найдёт данные: распакованные CSV, архив или (если ничего нет) скачает архив с GitHub.

**4. Признаки.** Сначала скачиваем внешние данные (нужен интернет, подробности в `data/README.md`):

```bash
python src/fetch_stations_osm.py
```

```bash
python src/fetch_postcode_lookup.py
```

Файл IMD 2019 (`ID 2019 for London.xlsx`) скачиваем вручную с [London Datastore](https://data.london.gov.uk/dataset/indices-of-deprivation) в `data/external/`. Затем добавляем признаки:

```bash
python src/add_features.py --data-dir data/raw/london --out-dir data/processed --stations data/external/stations_london.csv --postcodes data/external/postcode_lookup.csv --imd "data/external/ID 2019 for London.xlsx"
```

Без внешних файлов скрипт тоже работает, но добавит только группы, которые считаются из самих данных.

**5. Проверка вклада признаков и итоговый набор**

```bash
python src/ablation_multi.py --train data/processed/train_enriched.csv
```

```bash
python src/make_final.py
```

Результат: `data/processed/train_final.csv` и `test_final.csv`. Почему выбраны именно эти признаки, описано в [`FEATURES.md`](FEATURES.md).
