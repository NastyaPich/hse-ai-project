## 📌 Тема

**Предсказание общего спроса на недвижимость** (проект №76).

Спрос на недвижимость — ключевой индикатор состояния экономики и основной фактор динамики цен и инвестиционной привлекательности рынка. Мы строим модели, которые по макроэкономическим, демографическим, рыночным и пространственным признакам дают краткосрочные и долгосрочные прогнозы спроса, и исследуем, какие факторы влияют на него сильнее всего.

**Данные:** [China Real Estate Demand Prediction (Kaggle)](https://www.kaggle.com/competitions/china-real-estate-demand-prediction/data).

**Ключевые вызовы:** высокая вариативность данных, влияние неожиданных экономических и политических факторов, региональная специфика.

**Подход:** сначала классический ML (бейзлайны, feature engineering, градиентный бустинг), затем внедрение глубинного обучения и сравнение с ML-подходами.
