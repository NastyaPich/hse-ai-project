# Признаки для London House Price

Журнал признаков: откуда данные, как защищаемся от утечек, что дала проверка и что оставили.
Код: `src/add_features.py` (одна функция на группу), очистка: `src/clean.py`, проверка вклада групп (абляция): `src/ablation.py`, итоговый набор (список `KEEP`): `src/build_dataset.py`, скачивание внешних данных: `src/fetch_external.py`.
Исходные столбцы train/test не меняются, новые дописываются справа. Вся база собирается одной командой `python src/build_dataset.py`: очистка → признаки → итоговый набор.

## Охват данных
Все 282 872 объекта (train 266 325 + test 16 547) лежат в почтовых районах Лондона (E, EC, N, NW, SE, SW, W, WC; широта 51,39–51,67, долгота −0,35…0,14). «Ближайший крупный город» для всех один, Лондон, поэтому расстояния до других городов не имеют смысла. Вместо них добавлены расстояния до центров внутри Лондона.

## Защита от утечек
- Группы 3, 4, 6 используют цены. Для строки года Y берутся только продажи из прошлого: группы 3 и 6 используют год Y−1, группа 4 использует строго более ранние месяцы. Для test (2024) историей служит весь train.
- Лаг одинаковый у train и test (для 2024 это 2023), поэтому нет сдвига между выборками.
- Ставка Банка Англии берётся на 1-е число месяца продажи.
- Плотность `n_addr_500m` не использует цены.
- Признаки из цен (группы 3, 4, 6) считаются только по «чистой» истории: train без полных дубликатов и подозрительных цен (флаги `is_duplicate`, `price_suspect`, см. ниже). Иначе одна ошибочная цена попадает в признаки соседей.
- Группа 4 одинаково считается для train и test: последняя продажа того же адреса строго раньше месяца строки (`merge_asof`). Раньше для train брался предыдущий ряд в таблице, и при нескольких продажах в одном месяце более ранняя продажа терялась (832 строки train); для test результат не изменился.

## Очистка (`src/clean.py`, вариант «помечаем, не удаляем»)
Строки не удаляются, добавляются столбцы-флаги (0/1). Что исключать при обучении, решается на этапе моделей.

| Флаг | Правило | train | test |
|---|---|---|---|
| `pt_group` | 19 названий `propertyType` → 6 типов (EDA, раздел 4.1) | | |
| `is_duplicate` | полный дубликат строки (кроме ID), первая копия не помечается | 602 | 60 |
| `dup_addr_month` | у адреса несколько продаж в одном месяце с разной ценой | 1 839 | — |
| `price_suspect` | цена за м² < 300 £ или > 40 000 £ (EDA, раздел 5) | 1 021 | — |
| `area_suspect` | площадь = 10 м² или ≥ 499 м² | 30 | 2 |
| `addr_multi_unit` | у адреса две продажи с интервалом ≤ 3 месяцев: под адресом, видимо, несколько квартир | 12 761 (4,8%) | 541 (3,3%) |

Почему `addr_multi_unit`: у одного `fullAddress` бывает до 112 продаж, а площадь и комнаты у адреса всегда одинаковые. Две продажи «одного адреса» с интервалом 1–3 месяца отличаются по цене в среднем на 24%, для одной квартиры так не бывает. У таких адресов прогноз по прошлой продаже с поправкой ошибается сильнее (медиана 23% против 17%), поэтому флаг полезен модели. Флаг считается по датам продаж train и test, цены не используются.

Пропуски заполняются там же (`fill_missing`): в новых столбцах `*_filled` (площадь — медиана по типу жилья и числу спален, комнаты — медиана по типу, `tenure`, `currentEnergyRating`, `pt_group` — `Unknown`), рядом флаги `*_missing`. Медианы считаются только по train. Исходные столбцы не меняются; на расчёт признаков из цен заполнение не влияет.

## Ручная правка станций (`NOT_STATIONS`, `OPEN_YEAR_FIX` в `add_features.py`)
- Убрано 17 объектов, которые не являются станциями городского транспорта: выходы к самолётам и внутренний поезд аэропорта Хитроу, детские и парковые узкоколейки.
- Для 35 станций, открытых после 1995 года, задан год открытия (в OSM его не было): продление Jubilee line (1999), станции DLR (1996–2011), London Overground (2008–2010), продление Northern line (2021), Elizabeth line и Barking Riverside (2022). Без года станция считалась открытой всегда, и продажа 1996 года «видела» станцию, которой ещё нет.

## Результаты абляции (`src/ablation.py`)
Для каждого года Y из 2021, 2022, 2023 обучаемся на продажах до Y−1 и проверяем на Y; признаки с ценами пересчитываются только по истории до Y−1 (как для настоящего test). Модель одна и та же: `HistGradientBoostingRegressor`, цель log(цена). Показатель: RMSE по log(цена), среднее по трём годам (меньше — лучше). Посчитано на очищенной базе (признаки из цен только по train без дубликатов и подозрительных цен, исправленная прошлая продажа, правка станций). Полная таблица по годам: `reports/ablation_multi_result.csv`, график в EDA (раздел 7.9).

| Набор | Среднее RMSE 2021–2023 | Изменение к базе |
|---|---|---|
| базовые столбцы | 0,3736 | 0 |
| + прошлая продажа адреса | 0,3570 | −0,0166 |
| + расстояния до центров | 0,3705 | −0,0031 |
| + IMD | 0,3710 | −0,0026 |
| + транспорт | 0,3723 | −0,0013 |
| + плотность и цены ближайших продаж | 0,3725 | −0,0011 |
| + район (borough) | 0,3731 | −0,0005 |
| + ставка Банка Англии | 0,3757 | +0,0021 |
| + цены района за прошлый год | 0,3764 | +0,0028 |
| все группы | 0,3546 | −0,0190 |
| все, но без прошлой продажи | 0,3697 | −0,0039 |
| **итоговый набор (15 признаков)** | **0,3531** | **−0,0205** |

Выводы: прошлая продажа адреса даёт главный выигрыш во всех трёх годах; расстояния до центров, IMD, транспорт, плотность и район дают малый, но одинаковый по знаку выигрыш; ставка Банка Англии и цены района за прошлый год ухудшают результат. Итоговый набор не хуже, чем все группы сразу.

До очистки данных (первая версия базы) выводы были те же: только базовые столбцы 0,3740, все группы 0,3541, итоговые 15 признаков 0,3522 (первая проверка на одном 2023 году тоже показала главный вклад прошлой продажи и вред ставки).

Оговорка: разницы порядка 0,001–0,003 малы и могут быть шумом; доверительные интервалы не считались.

## Итоговый набор столбцов (`KEEP` в `src/build_dataset.py`)
Проверка по каждому столбцу: пропуски, сдвиг train/test (KS), корреляции между признаками (|Спирмен| ≥ 0,9) и проверка удалением по одному на годах 2021–2023.

**Оставляем (15 признаков + ключ):**
- прошлая продажа: `prev_sale_price`, `prev_price_adj`, `prev_sale_gap_months`
- центры: `dist_charing_cross_km`, `dist_canary_wharf_km`, `dist_nearest_centre_km`, `dist_subcentre_km`
- транспорт: `dist_station_km`, `dist_tube_km`
- окружение и район: `n_addr_500m`, `knn20_prev_med_logppsm`, `borough`
- IMD: `imd_score`, `crime_decile`, `living_env_decile`
- ключ для присоединения новых данных: `lsoa_code` (в модель не идёт)

Кроме признаков, итоговые таблицы содержат исходные столбцы, флаги очистки и заполненные пропуски (`*_filled`, `*_missing`, см. раздел «Очистка»).

**Убираем (18 столбцов):**
- `bank_rate_pct`, `bank_rate_chg_12m`: ухудшают результат на трёх годах. Возможная причина: в 2023 году изменение ставки за 12 месяцев (до +3,75 п.) больше любого значения в годах обучения (максимум +2,9). Уровень ставки в test (5–5,25%) при этом в пределах train: в 1995–2000 годах она была до 7,5%.
- `oc_prev_med_logprice`, `oc_prev_med_logppsm`, `oc_prev_n`, `oc_price_yoy`, `sec_prev_med_logppsm`, `sec_prev_n`: ухудшают результат, сильно дублируют `knn20_prev_med_logppsm`, счётчики сдвинуты между train и test.
- `n_prev_sales`, `knn20_prev_dist_km`, `n_stations_1km`: удаление не меняет качество.
- `dist_city_km`, `dist_west_end_km`: корреляция 0,93–0,98 с оставленными расстояниями.
- `imd_decile`, `income_decile`: корреляция 0,92–0,99 с `imd_score`.
- `nearest_subcentre`, `subcentre_tier`: не проверялись, текстовые, дублируют район и расстояния.
- `country` (исходный): всегда England.

Проверка удалением по одному (до очистки, RMSE по log цены, среднее 2021–2023): все 22 проверенных столбца 0,3524, оставленные 15 столбцов 0,3522, то есть разница в пределах шума.

## Ограничения
- Группа 5: станции в OSM описаны на сегодня. Код учитывает `open_year`; у новых станций год задан вручную (см. выше), но закрытые за 1995–2024 годы станции в выгрузке отсутствуют.
- Группы 7 и 8: IMD присоединился к 94,7% строк train и 91,5% строк test. Вероятная причина пропусков: postcodes.io выдаёт коды LSOA 2021 года, а IMD 2019 посчитан по кодам 2011 года. Исправить можно таблицей соответствия LSOA 2011 → 2021 (ONS). Названия столбцов в файле IMD ищутся по ключевым словам (`IMD_PATTERNS`); `load_imd` печатает, что нашёл.
- IMD 2019 это снимок на один год, а цены идут с 1995.
- Группа 4: предыдущая продажа есть у 55% строк train и у 76% строк test (у test за спиной вся история train; пропусков 45% и 24% соответственно).
- Группа 6: `n_addr_500m` считается по адресам из выборки продаж, а не по полному реестру домов. Это приближённая мера плотности.
- Группа 1: расстояния по прямой, не по дорогам. Часть центров London Plan вне области данных в список не включена.
- В данных есть выбросы цены (например, 99 млн £ за квартиру в 45 м²). Они помечены флагом `price_suspect` и не участвуют в расчёте признаков; решение, исключать ли их из обучения, принимается на этапе моделей.
